# roavilo-glm 项目架构和部署说明

更新日期：2026-10-05

本轮同步 Git 仓库、本地目录和数据库改名后的开发配置，并修复存储软链接；主域及各子域已统一更新为 `roavilo-glm.com`。当前数据库已执行 **11 条迁移**；历史页面回归记录见开发进度文档。

## 1. 总体架构

roavilo-glm 是**单 Laravel 13 应用 + 单主域（www.roavilo-glm.com）+ 响应式三端**架构，不同于 Moonker 的多 Host 前后端拆分：

```text
www.roavilo-glm.com（PC / iPad / 手机共用，CSS 断点自适应）
  └─ public/index.php → routes/web.php → Controller → Model → MySQL → Blade
       ├─ 前台：城市首页/分类/搜索/商户/团购/资讯/站点页（公开）
       ├─ auth 组：点评互动/收藏/订单/个人中心/商户中心
       └─ auth+admin 组：/admin 管理后台（独立深色布局）
m. / t. / kf. roavilo-glm.com
  └─ Nginx 反代回同一应用（m 为移动入口、t 对应 /t 团购、kf 对应 /kf 客服）
```

前端没有独立构建工程：`public/css/app.css` 为手写样式（含三端断点），交互脚本内联在 `layouts/app.blade.php`（搜索联想防抖、回到顶部）。`vite.config.js` 与 `resources/js` 保留框架默认，未启用。

## 2. 核心调用链

```text
前台浏览：/ → HomeController@root → CityService::resolve → redirect /{城市拼音}
城市首页：/{city} → HomeController@cityHome → City/Shop/Review/Deal 模型 → home.blade
分类列表：/{city}/ch{id} → ShopController@category → renderList() → shops/index.blade
关键词搜索：/search/keyword/{cityId}/0_{kw} → ShopController@search → renderList()
商户详情：/shop/{id} → ShopController@show（rf 评分筛选 + r_sort 排序 + 星级分布）→ shops/show.blade
团购闭环：/deal/{id} → OrderController@store（下单）→ pay（生成 verify_code）
        → MerchantController@verifyOrder（核销，状态 1→2）
点评闭环：POST /shop/{id}/review → ReviewController@store（updateOrCreate + 重算店铺评分）
        → like / reply（计数同步）
城市管理：/admin/* → AdminController（auth+admin 中间件）→ 审核/删除后重算评分
```

城市解析统一走 `App\Services\CityService`（session 缓存 + 默认上海 + session 容错）；`AppServiceProvider` 通过 View Composer 把 `$currentCity` 注入主布局供导航与搜索框使用。

## 3. 权限模型

单账号体系：`users.is_admin`（后台通行）+ `shops.owner_id`（店主身份）。入口保护分三层——路由 `auth` 组（登录）、`admin` 别名中间件 `EnsureUserIsAdmin`（管理员）、控制器内 `authorizeShop()`（店主）。已实测普通用户访问 /admin 403、非店主访问店铺管理 403。

## 4. 本地开发环境

当前开发配置（2026-10-05）：Git 仓库为 `https://github.com/saint-inc/roavilo-glm.git`；本地目录为 `<项目路径>/roavilo-glm`；本地数据库为 `roavilo-glm`，各开发者通过本地 `.env` 设置数据库凭据。网站品牌为 `roavilo-glm`，网站域名已更新为 `roavilo-glm.com`（含各子域）。目录改名后需执行 `php artisan storage:link --force` 重建存储软链接，并清理配置与视图缓存。

- PHP 8.5（Homebrew）、Laravel 13、MySQL 8（`127.0.0.1:3306`，库 `roavilo-glm`，凭据通过本地 `.env` 配置——必须用 IP 而非 localhost）。
- 依赖为 `composer install --no-dev`（网络原因暂缺 dev 依赖，PHPUnit 基线未建立）。
- 本地 `APP_URL=http://localhost:8000`；生产设置 `APP_URL=https://www.roavilo-glm.com`、`SESSION_DOMAIN=.roavilo-glm.com`。测试账号邮箱统一使用 `@roavilo-glm.com`，登录密码保持原值。
- 启动：`php artisan serve --port=8000`；测试账号 `test@roavilo-glm.com / password123`（管理员 + 1 号店主）。
- 重置：`php artisan migrate:fresh --seed --force`（会清空 orders/favorites/feedbacks 等人工测试数据）。
- 头像上传需 `php artisan storage:link`（已执行）。

## 5. 生产部署（CentOS Stream 8 + Nginx + PHP-FPM）

配置文件：`deploy/nginx/roavilo-glm.conf`（HTTP→HTTPS 301、主站 + m/t/kf 三个反代子域、PHP-FPM unix socket、静态资源 30 天缓存、隐藏文件 deny）。操作手册：`docs/部署指南-CentOS8.md`（依赖安装、数据库初始化、代码部署、certbot 证书、DNS 解析表、SELinux/firewall-cmd 放行、常用运维命令）。

要点：项目根指向 `public/`；`storage`、`bootstrap/cache` 需给 php-fpm 用户授权；上线执行 `config:cache && route:cache && view:cache`。**该配置未在真实 CentOS 服务器演练过**，首次部署须以 `nginx -t` 与全站 curl 回归收尾。

## 6. 与 dianping 的对标边界

URL path 结构、功能模块、交互逻辑（登录态差异/筛选/排序/核销）按公开可见的 dianping 模式实现；dianping 的视觉设计、图标、素材受版权保护，页面视觉为 roavilo-glm 原创设计，不承诺 1:1 像素复刻。dianping www/m/h5 主站有反爬，未逐页核对的部分不宣称"原样实现"。

## 7. 已知技术债

- 无 PHPUnit 自动化测试（手工 curl 回归，见《功能测试清单.md》）。
- 模拟支付无并发/幂等保护；`stock` 仅展示，下单未扣减。
- 点评图片、商户相册上传未接对象存储。
- 找回密码在生产必须改邮件下发（当前页面直接展示链接）。
- `feedbacks.status/reply` 的后台处理界面未建。
