## URL 路径结构对标（已完成 ✅ 2026-09-06）

roavilo 功能页面的 URL 路径与点评类平台（dianping）保持一致的结构：

| dianping URL 模式 | 功能 | roavilo 对应 | 状态 |
|---|---|---|---|
| `/{城市拼音}`（如 /shanghai） | 城市首页 | `/shanghai`、`/beijing` …（10 城市全支持） | ✅ |
| `/{城市}/ch{分类ID}` | 分类商户列表 | `/shanghai/ch1`（ch 后为 roavilo 分类 ID） | ✅ |
| `/search/keyword/{城市ID}/0_关键词` | 关键词搜索 | `/search/keyword/1/0_小笼包` | ✅ |
| `/shop/{商户ID}` | 商户详情 | `/shop/1` | ✅ |
| `/shop/{id}/fav` | 收藏商户 | `POST /shop/{id}/fav` | ✅ |
| `/deal/{团购ID}`（t. 子域） | 团购详情 | `/deal/1` | ✅ |
| t.dianping.com（子域根） | 团购列表 | `/t`（生产由 nginx t.roavilo.com 反代） | ✅ |

- **根路径** `/` → 302 跳转当前城市首页（session 记忆）
- **旧版 URL 全部 301 兼容跳转**：`/shops`→城市首页、`/shops/{id}`→`/shop/{id}`、`/city/{slug}`→`/{slug}`、`/deals`→`/t`、`/deals/{id}`→`/deal/{id}`
- **实现要点**：
  - 新增 `App\Services\CityService` 统一解析当前城市（session 缓存）
  - `AppServiceProvider` 通过 View Composer 向主布局注入 `$currentCity`（导航/搜索框用）
  - 城市 catch-all 路由 `/{city}` 置于路由文件末尾（避免吞掉 /user、/merchant 等）
  - 搜索关键词同时支持路径 `0_关键词` 与 query 参数 `?keyword=`
- **验证**：新 URL 11 个页面 200、旧 URL 5 条 301 跳转正确、中文搜索/点评发布/收藏在新路径下全部实测通过
- **本次修复**：Favorite 模型补 `$fillable`（此前收藏写入会报批量赋值异常）

## 遇到的问题与解决
- Laravel 13 移除 `Blueprint::unsignedDecimal` → 改用 `decimal()->unsigned()`
- Laravel 13 移除控制器构造器 `middleware()` → 全部改用路由中间件组
- MySQL ONLY_FULL_GROUP_BY 与关系带排序冲突 → 聚合查询改用独立 where 查询
- composer 安装 laravel/pint 从 GitHub 下载停滞 → 暂用 `--no-dev` 安装（后续需要测试时再补 dev 依赖）
- 本机 MySQL 需用 127.0.0.1 连接（localhost 走 socket 失败）
