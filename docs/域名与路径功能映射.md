# roavilo-glm 域名、子域名与路径功能映射

更新日期：2026-10-05

本文说明 roavilo-glm 的主域、子域入口与应用路由之间的关系，用于部署配置、链接检查和功能验收。域名以 `roavilo-glm.com` 为例，实际部署时需同步配置 DNS、HTTPS、Nginx 和应用中的子域匹配规则。

## 1. 主域与子域入口

| 域名 | 入口实现 | 承载功能 |
| --- | --- | --- |
| `roavilo-glm.com` / `www.roavilo-glm.com` | 主应用 | 城市首页、分类列表、搜索、商户详情、点评、团购、资讯及站点页面 |
| `m.roavilo-glm.com` | 与主站共用应用 | 手机访问入口，使用响应式页面及底部导航 |
| `t.roavilo-glm.com` | 根路径反代 `/t`，`/deal/*` 可直达 | 团购列表与详情 |
| `kf.roavilo-glm.com` | 根路径反代 `/kf` | 客服热线、常见问题与意见反馈 |
| `merchant.roavilo-glm.com` | 子域路径重写到 `/merchant` 前缀 | 店铺入驻、店铺看板、资料维护、点评回复、团购管理和订单核销 |
| `zhaopin.roavilo-glm.com` | 子域路径重写到 `/jobs` 前缀 | 招聘信息和邮件投递入口 |
| `h5.roavilo-glm.com` | 子域路径重写到 `/app` 前缀 | App 介绍页面，原生 App 尚未实现 |
| `union.roavilo-glm.com` | 业务路径统一映射到 `/union-gateway` | JSON 网关欢迎响应，尚未提供完整开放 API |

配置文件为 `deploy/nginx/roavilo-glm.conf`。商户、招聘、H5 和网关子域由 Nginx 透传 Host，应用在 `public/index.php` 中、创建请求对象之前重写 `REQUEST_URI`。

商户子域示例：`/` → `/merchant`，`/shops/1/dashboard` → `/merchant/shops/1/dashboard`。静态资源、登录注册及密码重置等认证路径，以及已带业务前缀的路径不重复改写。

主站的 `/merchant`、`/jobs` 和 `/app` 路径与对应子域入口同时保留。生产环境如需跨子域共享登录态，应配置 `SESSION_DOMAIN=.roavilo-glm.com`。

## 2. 主站业务路径

| 路径 | 方法 | 功能 |
| --- | --- | --- |
| `/` | GET | 302 跳转到当前城市首页 |
| `/{城市拼音}`，如 `/shanghai` | GET | 城市首页 |
| `/city` | GET | 城市选择与热门城市列表 |
| `/{城市}/ch{分类ID}` | GET | 分类商户列表 |
| `/{城市}/ch{分类ID}/g{区域ID}` | GET | 区域筛选后的商户列表 |
| `/search/keyword/{城市ID}/0_关键词` | GET | 关键词搜索，亦支持查询参数 `keyword` |
| `/api/search/suggest` | GET | 搜索联想 JSON 接口 |
| `/shop/{id}` | GET | 商户详情、评分分布与点评筛选排序 |
| `/shop/{id}/review` | POST | 提交点评 |
| `/shop/{id}/fav` | POST | 切换商户收藏状态 |
| `/reviews/{id}/like` | POST | 点评点赞 |
| `/reviews/{id}/reply` | POST | 点评回复 |
| `/t` | GET | 团购列表 |
| `/deal/{id}` | GET | 团购详情 |
| `/deal/{id}/order` | POST | 创建团购订单 |
| `/orders/{id}/pay` | POST | 模拟支付并生成核销码 |
| `/news` / `/news/{id}` | GET | 资讯列表与详情 |
| `/union-gateway` | GET | 网关欢迎响应 |

网关响应示例：

```json
{"code":200,"msg":"WelCome roavilo-glm union gateway!"}
```

路由中的 ID 应使用数据库内实际存在的记录。点评、收藏、订单等操作需按业务要求登录；商户和后台操作还需具备相应身份或权限。

## 3. 账号与管理页面

| 路径 | 功能 | 访问说明 |
| --- | --- | --- |
| `/login` / `/register` | 登录与注册 | 独立认证页面 |
| `/logout` | 退出登录 | POST 请求 |
| `/forgot-password` / `/reset-password/{token}` | 找回与重置密码 | 实际邮件发送需要配置邮件服务 |
| `/user` / `/user/reviews` / `/user/profile` | 个人中心、我的点评与资料维护 | 需登录 |
| `/favorites` / `/orders` / `/orders/{id}` | 收藏、订单列表与订单详情 | 需登录，订单详情校验所属用户 |
| `/merchant` / `/merchant/create` | 商户中心与店铺入驻 | 需登录 |
| `/merchant/shops/{shop}/*` | 店铺经营管理 | 校验店铺所属用户 |
| `/admin/*` | 用户、商户、点评、分类及城市管理 | 需管理员权限 |

## 5. 旧版 URL 兼容跳转

以下旧路径通过单跳 301 重定向到当前入口：

| 旧路径 | 跳转目标 |
| --- | --- |
| `/shops` | `/{当前城市拼音}` |
| `/shops/{id}` | `/shop/{id}` |
| `/city/{slug}` | `/{slug}` |
| `/deals` | `/t` |
| `/deals/{id}` | `/deal/{id}` |
