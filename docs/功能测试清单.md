## 二、登录/非登录状态差异（已实现）

| 场景 | 非登录态 | 登录态 |
|---|---|---|
| 顶栏右侧 | 「登录/注册」按钮 | 头像+昵称下拉菜单（我的主页/点评/收藏/订单/资料/商户中心/后台/退出） |
| 顶部提示条 | 引导登录条（立即登录/免费注册按钮） | 欢迎条（昵称问候+快捷入口） |
| 移动端底部 Tab | 第 4 个 Tab 显示「🔑登录」 | 第 4 个 Tab 显示「👤我的」 |
| 商户详情页 | 点赞/收藏/写点评区块隐藏或引导登录 | 显示完整互动表单 |
| 团购详情页 | 「登录后购买」按钮 | 显示数量选择+抢购表单 |
| 权限接口 | 访问需登录页 → 跳登录 | 正常访问；越权操作 → 403 |

## 五、三端响应式断点

| 设备 | 断点 | 行为 |
